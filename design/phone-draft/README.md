# Phone draft (#2)

PNG exports of the Penpot file **Trismegistus-android** (project Trismegistus), drawn by Hermes in the headless Penpot
session on optiplex (`penpot-agent`, homelab#7). Phone frames 412×892 (the S21 FE at 2.625×), light mode, Endfield
(paper with contour lines, the steel top bar and title rule of the Mac app), Inter and JetBrains Mono, colours from
the published Endfield Arch library. Built from the Mac app’s agreed design (09f, #41; kind tabs #48).

Navigation: **B, the drawer**, chosen by Martin on 2026-11-02 ("i really like it"). A and C stay as the record.
